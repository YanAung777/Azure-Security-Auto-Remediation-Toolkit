Frequently Asked Questions

Everything you need to know about our automated security remediation service.

How long does the initial setup take?

Our standard implementation takes 4 weeks. Week 1 is assessment and discovery, Week 2 is script development and testing, Week 3 is automation configuration, and Week 4 is deployment and hypercare. We can accelerate for urgent needs.

What Azure resources does this cover?

Our solution covers 45+ Azure services including Storage Accounts, Key Vaults, Virtual Machines, App Services, Function Apps, SQL Databases, API Management, Container Registries, and more. We continuously expand coverage based on new Azure security recommendations.

Will this break our existing applications?

No. Our scripts include comprehensive testing and what-if modes. We never apply changes without validation. Each script can be run in dry-run mode to preview impacts before execution. We also maintain rollback capabilities for all changes.

What permissions are required?

We require Security Admin and Contributor roles at the Management Group or Subscription level. We use least-privilege principles and store all credentials securely in Azure Key Vault. No interactive login required—fully automated execution.

Can we customize the remediation logic?

Absolutely. Every script is fully customizable to match your organization's specific requirements, naming conventions, and exception policies. We document all customizations and maintain them through updates.

What if we need to pause or cancel?

The $10K setup is a one-time investment that you own. The ongoing Enterprise Plus package requires a 6-month minimum commitment, after which you can cancel with 30 days notice. All deployed automation remains yours to operate independently.
